# Phase 2 - Opportunity Finder, Strategy Engine, Keyword Research Foundation

Build Opportunity Finder, opportunity scoring, expanded strategy generation, strategy approval, manual keyword import, automated keyword provider interface, and volume/difficulty fields.

Acceptance criteria:
- Opportunity Finder creates scored opportunities.
- User can approve one opportunity.
- Strategy Engine creates an approved plan.
- Keyword Research can run manually or automatically.
- Keyword results include search volume and difficulty when provider supports it.
