# Phase 8 - Social Media Engine, Monitoring, Admin Hardening

Build post generation, scheduling recommendations by channel, account integrations, mentions/comments monitoring, reply drafts, usage limits, admin monitoring, QA, and integration hardening.

Acceptance criteria:
- User can generate posts by platform.
- Approved posts can be scheduled.
- Mentions/comments can be monitored where platform APIs allow.
- Reply drafts require user approval.
- Admin can monitor usage, failures, and cost-related activity.
