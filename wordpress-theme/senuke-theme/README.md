# SENuke Theme

SENuke Theme is the editable WordPress block theme installed and synchronized by the SENuke AI Connector. Its layout system is built for responsive service-business websites and uses approved SENuke content, navigation, identity, media, forms and design tokens.

The theme contains no demo business claims, vendor branding, stock-template navigation or hard-coded customer information.

It includes editable header and footer parts, release-managed navigation, responsive service layouts, blog/archive/search/404 templates, narrow and blank-canvas page templates, WooCommerce compatibility, editor styles and accessible core markup. The theme is standalone and does not inherit from or require a parent theme.
